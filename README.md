# 2048 - パズルゲーム

楽しくて面白い **2048パズルゲーム** です！

## ゲーム説明

4×4のグリッド上でタイルを動かし、同じ数字を合わせて2倍にしていくゲームです。目指すは **2048**！

### 特徴
- **シンプルで中毒性がある** - 簡単ルールだが奥が深い
- **リアルタイムスコア計算** - プレイ中のスコアを表示
- **ハイスコア保存** - ブラウザに自動保存される
- **きれいなUIデザイン** - 楽しくプレイできる
- **レスポンシブ対応** - スマートフォンでもプレイ可能

## 遊び方

1. **矢印キー**（↑↓←→）でタイルを移動
2. **同じ数字が当たる**と合体して2倍になる
3. **2048を作ったらクリア！** 🎉
4. 動かせなくなったら**ゲームオーバー**

## ゲームルール

- タイルが移動するたびに、新しいタイル（2か4）がランダムに出現
- 合体させるとスコアが加算される
- ハイスコアは自動的にブラウザに保存される

## 遊び方

ブラウザで `index.html` を開くだけ！

```bash
open index.html
```

または、ローカルサーバーで実行：

```bash
python3 -m http.server 8000
# http://localhost:8000 にアクセス
```

## ファイル構成

- `index.html` - ゲームのHTML
- `styles.css` - デザイン・スタイル
- `game.js` - ゲームロジック
